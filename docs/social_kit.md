# Social media content kit

Five-card carousel copy (1080x1080 PNGs are generated by
`python scripts/generate_visuals.py` into `visuals/cards/`). Written for
technical football analysts - tactical coaching terminology (half-spaces,
low-blocks, transition vectors) with the data as evidence, not jargon.

## Carousel 1 - The decision (Twitter/X + LinkedIn)

- **Kicker:** THE DECISION
- **Header:** Which adjustment do we make NOW?
- **Body:** Opponent sits in a low block, denies central access. Our 4-3-3
  keeps circulating without penetration. A tactical decision engine asks:
  which change adds the most expected value to the next phase?

## Carousel 2 - The method

- **Kicker:** THE METHOD
- **Header:** From events to counterfactual value
- **Body:** Possessions -> 0-5 outcome scale + EPV. Unsupervised states ->
  named (low block, high press, transitions). IPW + doubly-robust estimation
  -> counterfactual adjustment value. Match-level bootstrap -> honest CIs.

## Carousel 3 - The state

- **Kicker:** STATE DETECTED
- **Header:** [detected state label, e.g. OPPONENT LOW BLOCK]
- **Body:** N comparable sequences detected. Baseline EPV per possession: X.
  Pressure proxy / passes per possession. Named states, never "Cluster 7".

## Carousel 4 - The recommendation

- **Kicker:** COACH-FACING OUTPUT
- **Header:** The recommended adjustment
- **Body:** State / adjustment / expected uplift in EPV per possession /
  95% CI / confidence / comparable sequences. Every estimate ships with its
  uncertainty.

## Carousel 5 - The validation

- **Kicker:** WHY TRUST IT
- **Header:** Validated on the future, not the past
- **Body:** Chronological split. Out-of-time RMSE + calibration ECE. Error
  analysis: 3 successes, 3 failures, and the data that would fix them.
  Human-in-the-loop: analyst notes, coach feedback, scout override.
